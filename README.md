# Nilesh Dwivedi — Portfolio Website

A simple responsive portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and resume content
- `style.css` — layout, colors, responsive styles and animations
- `script.js` — mobile navigation, theme toggle, reveal-on-scroll and current year

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser.

No build tools or frameworks are required. Google Fonts are loaded online; the site still works without them using fallback fonts.

## Customize
- Update text and project details in `index.html`.
- Change colors and layout in `style.css`.
- Add project or social links where needed. Project cards currently describe the work from the supplied resume and do not link to live demos.
